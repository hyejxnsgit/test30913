# 파란선

오늘 먹은 음식의 탄수화물과 당류를 기록하고, 누적된 내용을 원형 게이지로 확인하는 한국어 웹 앱입니다. HTML, CSS, JavaScript만 사용하며 별도 설치가 필요하지 않습니다.

## 실행 방법

브라우저에서 `index.html`을 열면 됩니다. 처음 열 때 2페이지 사용 안내가 표시되며, 이후에는 화면의 **사용 방법** 버튼으로 다시 볼 수 있습니다.

## 사용 방법

1. **글로 기록** 또는 **사진으로 기록** 탭을 선택합니다.
2. 음식 이름과 영양성분표의 탄수화물(g)을 입력합니다. 당류(g)는 선택 입력이며, 비워두면 0g으로 기록됩니다.
3. 사진 탭에서는 음식 사진을 촬영하거나 파일을 첨부한 뒤 영양정보를 직접 입력합니다.
4. **오늘의 기록에 추가**를 누르면 원형 게이지와 음식 목록이 갱신됩니다. 목록의 `×` 버튼으로 기록을 삭제할 수 있습니다.

기록은 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 다른 기기나 브라우저와 자동으로 동기화되지 않으며, 브라우저 저장 데이터를 지우면 기록도 사라질 수 있습니다.

## 게이지 기준

앱의 참고 점수는 `오늘 기록한 탄수화물(g) + 당류(g) × 0.25`로 계산합니다. 당류는 탄수화물에 포함되므로, 이 식은 앱 안에서 주의를 환기하기 위한 자체 기준입니다.

| 점수 | 단계 |
| --- | --- |
| 50 미만 | 적절 |
| 50 이상 100 미만 | 보통 |
| 100 이상 | 위험 |

게이지는 점수가 100에 도달하면 가득 차고, 위험 단계에서 음식을 추가할 때 화면 알림을 표시합니다. 이 점수와 단계는 실제 혈당 수치 또는 혈당 스파이크의 의학적 판정이 아닙니다. 실제 상태는 혈당 측정으로 확인해야 합니다.

## 사진 기능의 범위

사진은 음식 기록에 첨부됩니다. 사진에서 음식 종류나 영양성분을 자동으로 인식하지 않으므로, 제품의 영양성분표나 확인 가능한 자료를 보고 수치를 직접 입력해 주세요.

## 파일 구성

- `index.html`: 화면 구성과 안내 팝업
- `styles.css`: 비비드 블루 디자인과 반응형 레이아웃
- `app.js`: 기록 저장, 원형 게이지, 단계별 알림
